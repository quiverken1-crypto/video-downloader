# 多平台下载器整体思路

## 1. 产品定位

这是一个基于 **Electron + Chromium** 的 Windows 桌面下载器，面向 YouTube、Bilibili 和 Instagram。用户粘贴链接后，软件先读取标题、封面、平台及媒体数量，再把确认后的内容加入下载队列。

## 2. 整体流程

```text
用户粘贴链接
    ↓
识别所属平台并清理分享参数
    ↓
读取系统代理或使用手动代理
    ↓
获取标题、封面和媒体信息
    ↓
用户加入下载列表
    ↓
任务管理器并行调度（最多 3 项）
    ↓
yt-dlp / gallery-dl 下载
    ↓
FFmpeg 合并或转换音视频
    ↓
保存到 桌面\视频下载器\下载内容
```

## 3. 技术分工

- **Electron/Chromium**：负责桌面窗口、界面渲染和用户交互。
- **主进程**：负责链接检查、代理选择、任务调度、文件操作和本机接口。
- **yt-dlp**：处理 YouTube、Bilibili 及普通视频下载。
- **gallery-dl**：处理 Instagram 单图、多图和混合帖子。
- **FFmpeg**：合并分离的音视频流，并完成 MP3 等格式转换。
- **Preload + IPC**：在隔离网页界面与系统能力的同时，向界面提供限定功能。

## 4. 网络处理

软件默认读取 Windows 当前系统代理，因此发给其他人使用时不依赖固定端口。检查链接时只测试当前平台，减少等待；成功读取的结果缓存 5 分钟，重复链接可快速显示。

## 5. 下载队列

每个链接都是独立任务，状态包括等待、下载中、完成、失败和停止。任务管理器同时运行 3 项，其余任务自动排队。进度与状态通过事件推送到界面，避免频繁轮询和整页重绘。

## 6. 外部控制

程序启动后开放本机接口 `http://127.0.0.1:17896`，AI、脚本或其他小程序可通过 HTTP 提交链接、设置下载参数、查询任务和停止任务。

常用接口：

```text
GET  /health
POST /inspect
GET  /tasks
POST /tasks
POST /tasks/{id}/stop
POST /tasks/stop-all
```

## 7. 文件与运行体验

- 所有下载内容统一保存到桌面的「视频下载器\下载内容」。
- 外部下载工具以隐藏窗口方式运行，避免控制台反复弹出。
- 主界面采用固定布局，仅任务列表区域滚动。
- 程序可直接从桌面快捷方式启动，也可将 win64 压缩包发送给其他 Windows 用户。
